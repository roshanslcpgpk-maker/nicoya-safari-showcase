# Nicoya Safari Showcase

Create a polished, premium WEBSITE CONCEPT / DEMO for a Sri Lankan hospitality business called “Nicoya Safari Resort” in Habarana. This is an unsolicited portfolio concept for Source Code Software Solutions, NOT the official website and NOT a commissioned client project. Make this clear in a subtle small footer label: “Independent concept design by Source Code Software Solutions — not the official resort website.”

Design direction: immersive boutique jungle stay, premium editorial travel look, natural forest green, warm ivory, charcoal, muted brass accents, generous whitespace, excellent typography, tasteful motion only, responsive/mobile-first, visually rich. Do not make it look like a generic template.

Build a complete polished multi-section single-page site:
- Hero with beautiful Sri Lankan tropical forest / safari lodge imagery, headline “Your Habarana Escape, Close to the Wild”, short subheading, primary “Enquire on WhatsApp” CTA and secondary “Explore the Stay”
- About the stay, rooms section, amenities, safari experiences, photo gallery, location, FAQ, contact/enquiry section, footer.
- Use available public information conservatively: the resort is in Habarana, near Minneriya National Park; the listing describes 4 double air-conditioned rooms and says airport pickup, Sri Lanka tours, transport and safari arrangements may be arranged. Do not invent room prices, guest testimonials, awards, official policies, exact opening hours, or amenities not supported by the source. Mark unverified details as placeholders or omit them.
- Public listing phone seen for Nicoya Safari Resort: +94 77 809 4806. Use a WhatsApp CTA with this number only if the link can be safely constructed; otherwise show the number as visible contact information and label all contact details “verify before launch”. Do not claim this is an official website.
- Use high-quality image assets relevant to Habarana / Sri Lankan safari / boutique accommodation, but do not imply generated/stock images are actual resort photos; label gallery imagery as illustrative concept imagery or use an image treatment that makes it clear this is a design demo.
- Add an editable enquiry form UI with name, email/phone, preferred date, guests, and message. For this demo, do not store or send form submissions; show a clear demo confirmation message.
- Mobile navigation, accessibility, sensible semantic structure, working in-page navigation, responsive layout, SEO-friendly page title/description.
- Include a small, elegant concept badge so anyone seeing the demo understands this is a sample.
Aim for a highly convincing premium visual portfolio piece suitable for presenting to a potential business owner.
